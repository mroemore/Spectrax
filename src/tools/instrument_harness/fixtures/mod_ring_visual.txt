# Fixture: the modulation segment (Phase C part A).
#
# MODFORCE pins a dial's effective value (and optionally its base) so the
# rings can be photographed without waiting on an envelope's phase. RATIO1
# runs 0.25..30: base 15 puts the bright value ring across half the sweep,
# and the forced effective value runs the segment away from it in each
# direction, so the layer order (value ring under, segment over) is
# visible rather than inferred.
FRAMES 3
ASSERT selected==RATIO1

MODFORCE RATIO1 22.0 15.0
FRAMES 2
SHOT modring_positive.png

MODFORCE RATIO1 7.0 15.0
FRAMES 2
SHOT modring_negative.png
QUIT
