# add_route_delete.txt
# Xvfb-driven end-to-end test for the dynamic mod-source add / route / delete
# path. The script engine drives the same input handler the interactive loop
# uses, but synthesises key events directly into the InputState (raylib does
# not receive keyboard events under Xvfb/llvmpipe, so IsKeyPressed is useless
# here).
#
# Initial state after initApplication + SCENE_INSTRUMENT: the FM instrument
# has 4 envelopes (envelopeCount=4) and the graph selection sits on RATIO1.
#
# Layout of one runtime-envelope wrapper (envwrap, na_horizontal):
#   ATTACK   CURVE   DECAY   CURVE   ROUTE   blank
#
# Layout of the FM instrument root (instwrap, na_vertical):
#   presetWrap   btnwrap (RATIO1..FB2 LVL2 PAN)   pad2   modwrap (one ENVELOPE+ per envelope)
#
# Path from RATIO1 -> ATTACK of envelope[4] (the newly added one):
#   DOWN (to btnrow2) -> DOWN (to modwrap, head=true -> ATTACK of env[0])
#   then 4 more DOWNs to walk through env[0..3] to env[4].
# After ADD, envelopeCount goes 4 -> 5 (runtime envelope appended at index 4).

# --- ADD a runtime envelope ---
ADD
# Let the rebuild settle.
FRAMES 2
ASSERT envcount==5

# --- Navigate from RATIO1 down to the new envelope's ATTACK ---
DOWN
DOWN
DOWN
DOWN
DOWN
DOWN
# 6 DOWNs: 2 to leave btnwrap, 4 to walk modwrap from env[0] to env[4].
# Now selected should be ATTACK of envelope[4].
ASSERT selected==ATTACK

# --- Walk to the ROUTE dial ---
RIGHT
RIGHT
RIGHT
RIGHT
ASSERT selected==ROUTE

# --- EDIT RIGHT rewires: routeIndex wraps 12 -> 0 (op0 feedbackAmount). ---
EDIT RIGHT
ASSERT modulators==(0,0,1)

# --- Move to a sibling still inside the envelope wrapper, then REMOVE ---
LEFT
# Selected is now CURVE (the second one) inside ENVELOPE+.
REMOVE
FRAMES 1
ASSERT envcount==4

QUIT
